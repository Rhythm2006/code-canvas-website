What it does

  • Draw on your code. A transparent canvas sits over the editor, sharing one surface. One key flips which layer takes input.
  • Annotations travel with the project. Sketches are saved per file alongside your code.
  • A real terminal. A genuine login shell in the output panel — Run types the command, and you can type back to answer input() prompts.
  • Runs many languages using the toolchains already on your machine: Python, Node, Ruby, PHP, Go, C, C++, Rust, Java.
  • Export code + sketch as one PNG snapshot, or the drawing alone as PNG or SVG.
  • No license key, no trial, no watermark. The drawing engine is MIT, and the fonts ship inside the app — it works fully offline.
